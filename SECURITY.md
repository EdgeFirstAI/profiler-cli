# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the
EdgeFirst Profiler CLI or any of its installer scripts, please report
it privately to:

**support@au-zone.com** with subject prefix `[security]`

Include, where possible:

- A description of the issue and its impact.
- Steps to reproduce, including the affected version, OS, and
  architecture.
- Any proof-of-concept output or logs (with sensitive material
  redacted).

## What to Expect

- We acknowledge security reports within **5 business days**.
- We coordinate disclosure on a case-by-case basis with the reporter.
- We do not currently operate a public bug bounty programme.

## Supported Versions

Security fixes are issued against the **latest two minor releases**.
Older releases may receive fixes at our discretion.

## Public Issues

Please do **not** file public GitHub issues for suspected security
vulnerabilities. Use the email address above so we can address the
issue before public disclosure.
