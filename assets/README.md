# Assets

The PNGs in this directory are **transparent placeholders** at the
final intended dimensions. They will be replaced with real artwork
before any public announcement of the repository:

| File | Dimensions | Purpose |
|---|---|---|
| `hero.png` | 512×256 | Pixel-art hero illustration (top of README). |
| `hero@2x.png` | 1024×512 | HiDPI variant of the hero. |
| `mascot.png` | 256×256 | Optional pixel-art mascot for in-line use. |
| `edgefirst-wordmark-light.png` | 480×96 | EdgeFirst wordmark, light theme. |
| `edgefirst-wordmark-dark.png` | 480×96 | EdgeFirst wordmark, dark theme. |
| `tui-files.png` | 1024×512 | Literal capture of the TUI Files screen (F2). |
| `tui-profiler.png` | 1024×512 | Literal capture of the TUI Profiler screen (F4). |
| `completion.png` | 640×320 | Literal capture of the profiling-complete dialog. |

Pixel-art assets stay within the EdgeFirst palette: Navy `#3E3371`,
Balanced Gold `#E8B820`, Teal `#1FA0A8`, Soft Blue `#8FA3D4`, Deep
Indigo `#4B0082`. TUI screenshots are captured directly from the
binary with no styling applied.
